# СОБРАЛИСЬ.

Статичный штаб встреч для компании друзей: игры, кино, бары и любые другие планы.

## Что умеет

- создавать, редактировать и удалять встречи;
- отмечать ответы каждого участника: «В деле», «Думаю», «Пас»;
- фильтровать ближайшие и прошедшие активности;
- делиться одной встречей ссылкой-снимком;
- добавлять событие в календарь (`.ics`);
- экспортировать и импортировать резервную копию в JSON;
- хранить всё локально в браузере без регистрации.

## Важное ограничение

Сайт не использует сервер или базу данных, поэтому `localStorage` не синхронизируется между устройствами. Ссылка на встречу содержит её снимок в URL после `#`:

1. организатор создаёт план и отправляет ссылку в общий чат;
2. друг открывает ссылку, добавляет встречу и отмечает свой ответ;
3. обновлённую ссылку можно отправить обратно.

Для настоящей синхронизации в реальном времени позже понадобится внешний backend.

## Локальный запуск

Сайт не требует сборки. Можно открыть `index.html` напрямую или поднять любой статический сервер:

```powershell
python -m http.server 8080
```

После этого открыть `http://localhost:8080`.

## Публикация на GitHub Pages

1. Создать репозиторий на GitHub и загрузить файлы.
2. Открыть **Settings → Pages**.
3. В **Build and deployment** выбрать **Deploy from a branch**.
4. Выбрать ветку `main` и папку `/ (root)`, затем сохранить.

Все пути в проекте относительные, поэтому сайт работает и по адресу вида `username.github.io/repository/`.
